# Package index

## Panel Gaussian copula estimator

Fixed-effects panel Gaussian copula endogeneity correction (Haschka
2022).

- [`CopRegPANEL()`](https://ashgreat.github.io/endogCopulaPanel/reference/CopRegPANEL.md)
  : Panel copula correction for endogenous regressors with fixed effects

## Checking the identifying assumptions

Diagnostics for the identification requirements behind the estimator.

- [`validity(`*`<copregpanel>`*`)`](https://ashgreat.github.io/endogCopulaPanel/reference/validity.copregpanel.md)
  [`print(`*`<copregpanel.validity>`*`)`](https://ashgreat.github.io/endogCopulaPanel/reference/validity.copregpanel.md)
  : Validity / identification diagnostics for a fitted panel copula
  model
