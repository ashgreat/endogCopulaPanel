# Fitted values of a fitted panel copula model

Two scales are available. With `structural = TRUE` (the default) these
are the fitted values of `y = alpha_i + x'beta + z'delta + e` on the
original rows; with `structural = FALSE` they are the fitted values of
the FOD-transformed model on the transformed rows.

## Usage

``` r
# S3 method for class 'copregpanel'
fitted(object, structural = TRUE, ...)
```

## Arguments

- object:

  A fitted `"copregpanel"` object.

- structural:

  Logical; `TRUE` (the default) for the fitted values of the structural
  model, `FALSE` for the fitted values of the FOD-transformed model.

- ...:

  Currently unused.

## Value

A named numeric vector of fitted values.

## Examples

``` r
# \donttest{
set.seed(1)
N <- 30L; Time <- 6L
d <- data.frame(id = rep(seq_len(N), each = Time),
                 year = rep(seq_len(Time), times = N))
alpha <- rep(rnorm(N), each = Time)
e <- rnorm(N * Time)
d$x <- exp(rnorm(N * Time) + 0.5 * e)   # endogenous: correlated with e
d$z <- rnorm(N * Time)                  # exogenous
d$y <- alpha + 0.5 * d$x + d$z + e
fit <- CopRegPANEL(y ~ x | z, data = d, index = c("id", "year"),
                    nboots = 15, verbose = FALSE)
fitted(fit)
```
